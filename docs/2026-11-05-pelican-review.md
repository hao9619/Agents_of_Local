此前失败为 Tool mkdir not found / Tool write_file not found，属于调用了不存在的接口。当前 `create_new_file` 在 Continue 中启用，策略为 Ask First；用户点击批准后由插件执行写入，不需要用户手动复制文件内容。若希望免逐次批准，可在工具设置中仅将此工具设为 Automatic。不要把所有工具一并改为自动，也不要以提示词“无需确认”当作已改变插件策略。

把任务缩到单个明确文件路径，要求直接调用 create_new_file，并在同一请求中重新给出完整动画要求，避免只说“写入上面的代码”。新增文件与修改已存在文件应使用各自实际提供的工具，不能再对已有文件盲目调用新建接口。文件已存在时，先确认内容及相应编辑工具。
